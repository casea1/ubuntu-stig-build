#### Vitis Unified Software Platform Install Configuration ####

# Captured from dev-15, 2026-09-03, and committed so every workstation installs
# the SAME modules and device families. Regenerate with `./xsetup -b ConfigGen`
# and re-capture with `it-fpga install --save-config` if the selection changes.
#
# Two lines were changed from the captured original, both deliberate:
#   CreateProgramGroupShortcuts / CreateDesktopShortcuts -> 0
# The installer runs under sudo, so its shortcuts land in /root/Desktop where
# no engineer ever sees them -- which is exactly why a correctly installed
# Vivado looked like a missing one. fpga_tools writes system-wide entries in
# /usr/share/applications instead, for every user, and removes them if the
# toolchain goes away.
